# Pakistan Rattan Furniture Atelier — Islamabad

Handcrafted cane seating, natural rattan furniture, and bespoke architectural woodwork in Islamabad, Pakistan.

## Features

- **Curated Cane & Hardwood Catalog:** Browse heirloom lounge seating, dining sets, and architectural cane partitions with interactive weave and timber finish selectors.
- **Bespoke Commission Configurator:** Customize dimensions, cane mesh patterns (*Octagonal French Weave*, *Close Diamond Mesh*, *Double-Wall Rattan Core*), and seasoned Pakistani hardwoods (*Kiln-Dried Teak*, *Seasoned Sheesham*).
- **Direct Islamabad Atelier Inquiry & Order Flow:** Submit custom commission requests directly to the Islamabad workshop (`+92 302 4195970`) via WhatsApp or book a private showroom consultation.
- **Integrated GitHub Publisher:** Connect via GitHub OAuth to push the full source code and standalone GitHub Pages bundle directly to your GitHub account.
